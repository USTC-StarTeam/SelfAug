1. Method At A Glance

SelfAug aligns input-sequence logits during RAG fine-tuning to reduce catastrophic forgetting while preserving downstream learning.

1. Uses

Uses input-sequence logits from the original model as the alignment target.

2. Combines

Combines downstream NLL with a KL-divergence alignment loss.

3. Requires

Requires no replay data or response-generation validation loop.

2. Code And Usage

Start from the repository commands below, then follow README details for data paths, model checkpoints, and evaluation outputs.

# then continue normal LoRA fine-tuning with transformers and peft
